**Warung Rush** — an original time-management cooking game set in an Indonesian warung. Take orders from the board (Nasi Goreng, Mie Goreng, Ayam Geprek, Soto Ayam, Nasi Campur), build each dish from six ingredient stations in the wajan, panci or on the plate, pull it off the heat in the golden window before it burns, and serve it from the pass before the customer's patience runs out. Fast, perfect serves earn coins and grow a combo multiplier across a 150-second shift that ends with a score and star rating. Everything is drawn in code on a canvas and every sound is synthesized with WebAudio: static files, no build step, no network. Mouse plus keyboard (1–6 ingredients, Q/W/E spots, Space to serve, Backspace to bin). Deterministic screenshot scenes live behind `?shot=start|play|serve|end&seed=1`.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or serve game/ with any static file server
```
